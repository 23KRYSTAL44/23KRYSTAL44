# Программные продукты с ясной структурой.

`23KRYSTAL44-STUDIO` — независимая разработка нативных продуктов, надёжных систем, продуманной автоматизации и решений на основе прикладного ИИ.

Работа начинается с чёткой задачи и заканчивается программным продуктом, которым удобно пользоваться, который легко развивать и не приходится переписывать при первом изменении требований.

## Направления

- **Нативные продукты** — приложения для платформ Apple, построенные вокруг реальных пользовательских сценариев.
- **Локальные системы** — осознанное владение данными, работа без обязательного подключения к сети и чёткие границы приватности.
- **Качество как часть продукта** — доступность, тестирование, документация и поддерживаемые процессы доставки.
- **Практичная автоматизация** — инструменты и процессы с поддержкой ИИ, которые убирают рутину, не скрывая устройство системы.

## Сейчас в работе

Текущие продукты остаются в закрытой разработке, пока не подготовлены релизные версии, публичная документация и способ распространения. Проекты появятся здесь, когда ими уже можно будет пользоваться, а не просто показать.

## Технологии

- **Нативная разработка** — `Swift` `SwiftUI` `SwiftData`
- **Качество** — `Swift Testing` `XCTest` `XCUITest` `Accessibility`
- **Инженерные процессы** — `Git` `GitHub Actions` `CI/CD` `Technical documentation`
- **Автоматизация и ИИ** — `Python` `Automation` `LLM workflows`

## Принципы студии

- Ясность важнее украшений.
- Приватность важнее сбора данных.
- Проверяемые факты важнее заявлений.
- Завершённость важнее количества.
