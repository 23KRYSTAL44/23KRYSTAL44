# Visual Identity

The profile uses a restrained, GitHub-native system designed to remain legible in both interface themes.

- **Ink:** `#0D1117`
- **Paper:** `#F6F8FA`
- **Mineral blue:** `#0969DA` / `#58A6FF`
- **Secondary text:** `#57606A` / `#8B949E`
- **Type:** system UI for prose; system monospace for the wordmark and technical labels
- **Signature:** a single-line crystalline path that references the `KRYSTAL` name without becoming a literal gem logo

`hero-light.svg` and `hero-dark.svg` are selected by the visitor's color scheme. `avatar.svg` and `social-preview.svg` are editable sources; their PNG exports are intended for GitHub's upload-only profile and social-preview controls.
